# Quill for Mac

Your words. Your voice. A British English writing assistant for macOS, with local checking and optional AI using your own OpenAI API key.

## Download

Get the **Apple Silicon DMG** and **Getting Started PDF** from [the latest release](https://github.com/GavinRanton/quill-releases/releases/latest). Drag Quill into Applications, then open the installed copy. Quill lives in the menu bar.

Requires Apple silicon (M1 or later). The app targets macOS 13 or newer; fresh-Mac and full supported-OS qualification remain incomplete. This is an early preview. An M2 launch failure has been reported and is under investigation; the updater release does not claim to fix it.

## Updates

Version 0.12.0 and later connect to this repository's release feed through Sparkle. Automatic checks and background download/installation default to on and can be changed in Settings > Help & About. Installation may finish when Quill quits or require a relaunch/permission prompt. Quill must run and have internet access; updates are not pushed instantly.

**Version 0.11.0 and earlier need a one-time manual installation of a connected release.** The Chrome extension can require a separate reload when its files change.

Updates are signed with Quill's update key and the app is Developer ID signed and Apple-notarised. This repository contains release downloads and public update metadata; it does not contain user writing, API keys or personal settings.

## Before trying it

Local checks work without an account or key. Optional AI sends writing to OpenAI and uses the recipient's own paid API access. See the guide for when text is sent and how to configure Chrome. Review suggestions before accepting them.

TextEdit selection review has been tested. Notes, Pages and Mail depend on the editor exposing a selection and remain unqualified. WhatsApp supports review/copy; direct Apply and Telegram integration are unavailable. Automatic start at login is not included.

## Feedback

Open an issue with your macOS version, chip, Quill version and exact error or a non-sensitive example. Do not post API keys, private writing or unredacted personal information.
